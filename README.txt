Desc:
Wizard's Lair is a simple encounter and loot generator for D&D 5e 
designed to eliminate the tedious math of session prep.
Instantly build thematic combat encounters and roll balanced treasure hoards in a single click,
so you can spend less time calculating and more time running your game.
